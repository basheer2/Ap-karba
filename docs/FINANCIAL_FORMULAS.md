# القواعد والمعادلات المالية (Financial Formulas & Business Rules)

## القواعد الصارمة للحسابات المالية (Strict Rules)
1. **لا استخدام إطلاقاً للـ Floating Point (Double/Float)** في التخزين المالي؛ التخزين إما كـ `Long` بالأصغر وحدة نقدية، أو دوال تقريب دقيقة بدون كسور عائمة.
2. **العملة الافتراضية**: الريال اليمني (YER).

## المعادلات الأساسية (Core Formulas)
### 1. الإنجاز والعمل اليومي
```
قيمة العمل = الكمية × سعر الوحدة
Total = Quantity × UnitPrice
```

### 2. حضور وأجور العمال
```
أجر اليوم المستحق = الأجر اليومي × نسبة العمل (Ratio)
حيث:
- حاضر (PRESENT): ratio = 1.0
- نصف يوم (HALF_DAY): ratio = 0.5
- غائب (ABSENT): ratio = 0.0
- إجازة (LEAVE): ratio = 0.0 أو مدفوعة حسب الاتفاق

إجمالي مستحقات العامل = مجموع (أجور الحضور اليومية لكافة الأيام)
إجمالي مدفوعات العامل = مجموع (السلف + الدفعات الأسبوعية والنهائية)
رصيد العامل المتبقي = إجمالي المستحقات − إجمالي المدفوعات
(إذا كان الناتج موجباً: مستحق للعامل، وإذا سالباً: متبقي عليه سلف)
```

### 3. العقود وأوامر التغيير
```
القيمة الحالية للعقد = القيمة المبدئية للعقد + مجموع (أوامر التغيير المعتمدة APPROVED)
الدفعة المقدمة المدفوعة = سندات القبض المرتبطة بالعقد
المتبقي من العقد = القيمة الحالية للعقد − إجمالي المبالغ المقبوضة
```

### 4. الفواتير
```
المجموع الفرعي (Subtotal) = مجموع (الكمية × السعر لكل بند)
الإجمالي النهائي = المجموع الفرعي − مبلغ الخصم + مبلغ الضريبة
المتبقي من الفاتورة = الإجمالي النهائي − إجمالي المدفوعات المسجلة عليها
حالة الفاتورة:
- إذا المدفوع = 0 => صادرة (ISSUED)
- إذا المدفوع < الإجمالي => مدفوعة جزئياً (PARTIALLY_PAID)
- إذا المدفوع >= الإجمالي => مدفوعة بالكامل (PAID)
- إذا انتهى تاريخ الاستحقاق ولم تسدد => متأخرة (OVERDUE)
```

### 5. سندات القبض والصرف
- سند القبض (Receipt): تدفق نقدي وارد (+)، يقلل من مديونية العميل.
- سند الصرف (Payment Voucher): تدفق نقدي صادر (−)، يقلل من مستحقات العامل أو المورد.

### 6. التدفق النقدي (Cash Flow)
```
صافي التدفق النقدي = إجمالي المقبوضات (سندات القبض) − إجمالي المدفوعات (سندات الصرف + المصروفات المباشرة)
```

### 7. ربحية المشروع (Project Profitability)
```
إيرادات المشروع = مجموع (سندات القبض المعتمدة + فواتير المشروع)
تكلفة العمال للمشروع = مجموع (مستحقات العمال المسجلة على المشروع)
مصروفات المشروع = مجموع (المصروفات المباشرة المسجلة على المشروع)
التكلفة الإجمالية = تكلفة العمال + المصروفات
صافي ربح المشروع = الإيرادات − التكلفة الإجمالية
هامش الربح % = (صافي الربح ÷ الإيرادات) × 100
```

### 8. ربحية المرحلة (Stage Profitability)
```
إيراد المرحلة = مجموع إنجاز البنود للمرحلة
تكلفة عمال المرحلة = مجموع أجور العمال في المرحلة
مصروفات المرحلة = مجموع فواتير ومشتريات المرحلة
صافي ربح المرحلة = إيراد المرحلة − (تكلفة العمال + المصروفات)
```

### 9. التفقيط العربي (Tafqeet)
تحويل الرقم الصحيح إلى كلمات عربية فصحى:
مثال: 350000 => «ثلاثمائة وخمسون ألف ريال يمني فقط لا غير».
