# خريطة التنقل والشاشات (Navigation Map) — كهرباني

### 1. شريط التنقل السفلي الرئيسي (Bottom Navigation)
1. **الرئيسية (Dashboard)**:
   - مؤشرات الأداء الحيوية (المشاريع، التدفق المالي، الأرباح، المستحقات).
   - بطاقات مخصصة قابلة للترتيب والإخفاء.
   - أزرار الإجراء السريع (FAB Speed Dial): مشروع جديد، عمل اليوم، سند قبض، سند صرف، فاتورة، مصروف.
   - ملخص نشاط اليوم والتنبيهات.

2. **عمل اليوم (Daily Work)**:
   - تسجيل إنجاز سريع بنقرتين (المشروع، المرحلة، البند، الكمية، العامل).
   - جدول الحضور السريع اليومي لفريق العمل بنقرة واحدة (حاضر / نصف يوم / غائب).
   - سجل الأعمال اليومية المنجزة مع إمكانية التعديل والحذف.

3. **المشاريع (Projects)**:
   - قائمة المشاريع مع الفرز والفلترة (جديد، نشط، متوقف، مكتمل).
   - تفاصيل المشروع الشاملة (المراحل، خطة التنفيذ المخطط مقابل الفعلي، الإنجاز، المصروفات، أجور العمال، الربحية، المخططات، العيوب، محاضر التسليم).

4. **الفريق (People & Workers)**:
   - قائمة العمال والفنيين وأجورهم اليومية.
   - كشف حساب كل عامل (سجل الحضور، المستحقات، السلف، الدفعات، الرصيد المتبقي).
   - تسجيل سلفة أو دفعة جديدة فورياً وسند صرف.

5. **المزيد (More Modules Hub)**:
   - **العملاء (Clients)**: كشوفات الحساب، الفواتير، الدفعات، العقود.
   - **العقود وأوامر التغيير (Contracts & Change Orders)**: إبرام عقد، اعتماد أمر تغيير وتحديث القيمة تلقائياً.
   - **الفواتير وسندات القبض (Invoices & Receipts)**: إصدار فاتورة، بنود الفاتورة، تسجيل دفعة أو سند قبض، طباعة وتصدير.
   - **المصروفات والتدفق النقدي (Expenses & Cash Flow)**: تسجيل مصروف بتصنيفاته، متابعة السيولة النقدية اليومية والشهرية.
   - **العيوب والملاحظات (Defects)**: متابعة الملاحظات حسب الأولوية، مع الصور قبل وبعد.
   - **محاضر التسليم (Handovers)**: محاضر مبدئية ونهائية مع Checklist التوصيلات والتأريض، والتوقيع الرقمي الحي.
   - **المخططات والوسائط (Media & Blueprints)**: مخططات الإنارة والقوى، أرشفة الصور والمقارنة.
   - **التقارير وكشوف الحساب (Reports & PDF)**: تقرير الأرباح، كشف الحساب للعميل، تقرير الحضور، تقرير المشاريع.
   - **استوديو كود Android Studio (Android Exporter)**: استعراض وتنزيل حزمة مشروع Android Studio الكاملة بصيغة Kotlin & Gradle.
   - **النسخ الاحتياطي والأمان (Backup, PIN & Privacy)**: تصدير واستيراد البيانات، قفل PIN، حجب الأرقام المالية.
