# كهرباني (Kahrabani) — نظام إدارة المقاول الكهربائي

نظام متكامل واحترافي لإدارة أعمال المقاول الكهربائي والمشاريع والعمال والعملاء والعقود والفواتير والمصروفات والإنجاز والربحية والملفات والتسليمات.

---

## 1. الهيكل المعماري (Architecture)
تم بناء النظام وفق معمارية **Clean Architecture + MVVM** مع مبدأ **Offline-First Reactive Flow**:
- **Presentation**: Jetpack Compose + Material 3 باللغة العربية مع دعم RTL كامل وتوقيع رقمي باللمس.
- **Domain**: Use Cases خالصة لحساب الأرباح، أجور الحضور، مديونيات العملاء، وتحديث العقود تلقائياً.
- **Data**: Room Database مع فهارس (Indexes) ومفاتيح خارجية (Foreign Keys).
- **Security**: Keystore + PIN Lock + وضع الخصوصية المالية لحجب المبالغ (••••••).

## 2. أقسام ووحدات النظام (Modules)
1. **لوحة التحكم (Dashboard)**: مؤشرات حيوية، الأرباح، التدفق النقدي، المبالغ المستحقة، وإجراءات سريعة.
2. **عمل اليوم (Daily Work)**: تسجيل إنجاز سريع بنقرتين وتسجيل حضور الفنيين اليومي بنقرة واحدة (حاضر / نصف يوم / غائب).
3. **المشاريع والمراحل (Projects & Stages)**: خطة التنفيذ المخطط مقابل الفعلي، مراحل التأسيس وسحب الأسلاك والتشطيب، وتحليل الربحية.
4. **فريق العمل والعمال (Workers)**: كشف حساب العامل، المستحقات، السلف، وسندات الصرف.
5. **العملاء (Clients)**: كشوف الحساب، الفواتير، وسندات القبض.
6. **العقود وأوامر التغيير (Contracts & Change Orders)**: تحديث قيمة العقد تلقائياً عند اعتماد أمر التغيير.
7. **المالية والتدفق النقدي (Finance & Cash Flow)**: فواتير، سندات قبض، سندات صرف، مصروفات مباشرة مصنفة.
8. **العيوب والملاحظات (Defects)**: متابعة الملاحظات حسب الأولوية الفنية (منخفضة، متوسطة، عالية، حرجة).
9. **محاضر التسليم (Handovers)**: تسليم مبدئي ونهائي مع قوائم تدقيق السلامة وتوقيعات رقمية حية باللمس.
10. **المخططات والوسائط (Media & Blueprints)**: مخططات الإنارة والقوى، أداة مقارنة الموقع قبل وبعد التنفيذ.
11. **التقارير و PDF (Reports)**: تفقيط الأرقام باللغة العربية (ريال يمني)، كشوفات حساب مفصلة قابلة للطباعة.
12. **استوديو كود Android Studio**: استعراض وتحميل حزمة مشروع Android Studio الكاملة بنقرة واحدة (ZIP).

## 3. تشغيل وبناء مشروع Android Studio (Build & Run)
1. تأكد من تثبيت **Android Studio Ladybug (2024.2.1)** أو أحدث مع **JDK 17**.
2. افتح المجلد `android/` في Android Studio.
3. انتظر انتهاء Gradle Sync.
4. للبناء والتجربة:
   ```bash
   ./gradlew assembleDebug
   ```
5. لتشغيل الاختبارات الأحادية (Unit Tests):
   ```bash
   ./gradlew testDebugUnitTest
   ```
6. لإنشاء نسخة الإنتاج (Release APK / Bundle):
   ```bash
   ./gradlew assembleRelease
   # أو
   ./gradlew bundleRelease
   ```

## 4. قاعدة البيانات المحلية (Room Database & Migrations)
- توجد قاعدة البيانات في `com.kahrabani.app.data.local.KahrabaniDatabase`.
- يتم ترقيم الجداول والكيانات مع دعم `Versioned Migrations`:
  - `v1 -> v2`: إضافة حقول التتبع والمزامنة.

---

## 5. النسخ الاحتياطي والاستعادة (Backup & Restore)
- يدعم النظام تصدير نسخة احتياطية كاملة بصيغة `JSON` تتضمن جميع الكيانات، الإعدادات، والسجلات مع التحقق من سلامة البيانات (Checksum Validation).
- استعادة فورية مع فحص النسخة قبل التطبيق.
